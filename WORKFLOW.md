## 📝 变更提案示例

### 目录结构
```
changes/001-user-login/v1/
├── proposal.md      # pm 创建
├── design.md        # arch 创建
├── openapi.yaml     # arch 创建
├── schema.prisma    # arch 创建
├── tasks.md         # arch 创建
├── flags/           # 状态标记
│   ├── be.done
│   ├── fe.done
│   └── mobile.done
└── status.md        # pm 创建
```

### proposal.md 模板
```markdown
# 变更提案：001-user-login

## 版本
v1

## 背景
用户需要登录系统才能使用核心功能

## 目标
- 支持邮箱 + 密码登录
- 支持记住登录状态
- 支持登录失败次数限制

## 验收标准
- [ ] 正确邮箱密码可登录
- [ ] 错误密码提示友好
- [ ] 连续 5 次失败锁定 30 分钟

## @arch 请设计技术方案
```

---

## ⚠️ 注意事项

1. **只在指定目录开发** — 不要在主工作区或其他地方创建项目
2. **版本化管理** — 需求变更时创建新版本 (v1 → v2)
3. **保留历史** — 所有版本都保留
4. **及时更新状态** — 完成后立即创建 `flags/*.done`
