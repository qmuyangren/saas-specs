## 背景
用户需要登录系统才能使用核心功能，这是 SaaS 平台的基础功能。

## 目标
- 支持邮箱 + 密码登录
- 支持记住登录状态（7 天免登录）
- 支持登录失败次数限制（5 次/30 分钟）
- 登录后跳转首页

## 用户故事
作为注册用户，我希望通过邮箱和密码登录系统，以便使用平台功能。

## 功能列表
- [ ] 登录表单（邮箱、密码）
- [ ] 记住我选项
- [ ] 密码加密存储
- [ ] JWT Token 生成
- [ ] 登录失败限流
- [ ] 登录成功跳转

## 验收标准
- [ ] 正确邮箱密码可登录，返回 Token
- [ ] 错误密码提示"密码错误"
- [ ] 连续 5 次失败锁定 30 分钟
- [ ] Token 有效期 7 天（记住我）或 2 小时（不记住）
- [ ] 登录后自动跳转到首页

## 非功能需求
- 响应时间 < 200ms
- 支持并发登录 1000+ 用户

## 优先级
**P0** - 核心功能，优先开发
