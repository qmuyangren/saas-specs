## 背景

当前前端界面使用默认主题，需要根据品牌色和用户偏好调整 UI 主题，提升视觉体验。

## 目标

- 调整主色调为品牌色
- 优化暗色模式
- 统一组件样式
- 提升可访问性

## 用户故事

作为**普通用户**，我希望**界面主题美观舒适**，以便**获得更好的使用体验**。

## 功能列表

- [ ] 主色调调整（品牌色：#1890ff）
- [ ] 辅助色定义（成功/警告/错误）
- [ ] 暗色模式优化
- [ ] 字体大小统一
- [ ] 圆角风格统一
- [ ] 阴影效果优化

## 验收标准

- [ ] 主色调符合品牌规范
- [ ] 明/暗主题切换流畅
- [ ] 所有组件样式一致
- [ ] 对比度符合 WCAG 2.1 AA 标准
- [ ] 支持用户自定义主题

## 优先级

**P1** - 提升用户体验

## 技术要求

- 使用 CSS Variables 实现主题
- 支持运行时切换
- 主题配置可持久化
