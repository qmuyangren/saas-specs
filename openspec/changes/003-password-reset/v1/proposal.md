## 背景

用户忘记密码后需要找回账户访问权限。当前系统只有登录功能，缺少密码重置机制。

## 目标

- 支持通过邮箱验证码重置密码
- 支持密码强度验证
- 支持重置链接有效期控制

## 用户故事

作为**已注册用户**，我希望**通过邮箱验证重置密码**，以便**在忘记密码时恢复账户访问**。

## 功能列表

- [ ] 发送重置验证码到注册邮箱
- [ ] 验证验证码有效性
- [ ] 重置密码（需符合密码强度要求）
- [ ] 验证码过期处理（5 分钟）
- [ ] 发送频率限制（1 分钟 1 次，每天 5 次）

## 验收标准

- [ ] 未注册邮箱发送验证码提示"该邮箱未注册"
- [ ] 验证码错误提示友好
- [ ] 验证码过期提示"验证码已过期，请重新发送"
- [ ] 新密码必须符合强度要求（6-20 位，含字母和数字）
- [ ] 密码重置成功后，旧 token 失效
- [ ] 密码重置成功后，自动登录

## 优先级

**P0** - 核心安全功能

## 安全要求

- 验证码随机生成（6 位数字）
- 验证码存储到 Redis，5 分钟过期
- 密码使用 bcrypt 加密
- 重置成功后记录操作日志
