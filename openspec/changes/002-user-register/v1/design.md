## 技术选型

| 模块 | 技术 | 理由 |
|------|------|------|
| 验证码 | Redis | 高性能、支持过期时间 |
| 邮件发送 | nodemailer | 成熟稳定、支持 SMTP |
| 密码加密 | bcrypt | 标准方案 |
| 表单验证 | class-validator | 与 NestJS 集成好 |

## 流程设计

### 注册流程
```
1. 用户填写注册表单
2. 前端验证格式
3. 请求发送验证码 API
4. 用户输入验证码
5. 提交注册请求
6. 后端验证验证码
7. 创建用户
8. 自动登录（返回 Token）
```

### 验证码发送限流
```
- 同一邮箱：1 分钟 1 次
- 同一 IP：每天 10 次
- 验证码有效期：5 分钟
```

## 安全设计

### 密码强度
- 长度：6-20 位
- 包含：字母 + 数字
- 前端加密：SHA-256
- 后端加密：bcrypt (salt rounds: 10)

### 防刷机制
- Redis 计数：`register:code:{email}`
- IP 限流：`register:ip:{ip}`

## API 设计

见 `openapi.yaml`

## 数据模型

复用 001-user-login 的 User 表，无需修改。

## 风险评估

| 风险 | 影响 | 应对 |
|------|------|------|
| 验证码泄露 | 中 | 限流、有效期短 |
| 恶意注册 | 中 | 邮箱验证、IP 限流 |
| 密码强度弱 | 高 | 强制强度验证 |
