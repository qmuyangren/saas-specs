## 背景
用户需要注册账号才能使用系统，这是 SaaS 平台的基础功能，与登录功能配合使用。

## 目标
- 支持邮箱注册
- 支持密码强度验证
- 支持邮箱验证码
- 防止重复注册
- 注册后自动登录

## 用户故事
作为新用户，我希望通过邮箱注册账号，以便使用平台功能。

## 功能列表
- [ ] 注册表单（邮箱、密码、确认密码）
- [ ] 邮箱验证码发送
- [ ] 邮箱验证码验证
- [ ] 密码强度验证
- [ ] 邮箱唯一性检查
- [ ] 注册后自动登录

## 验收标准
- [ ] 邮箱格式正确才能提交
- [ ] 密码长度 6-20 位，包含字母和数字
- [ ] 验证码有效期 5 分钟
- [ ] 已注册邮箱提示"该邮箱已注册"
- [ ] 注册成功后自动登录并跳转首页
- [ ] 同一邮箱 1 分钟内只能发送 1 次验证码

## 非功能需求
- 验证码使用 Redis 缓存
- 密码前端加密传输
- 防刷限制：同一 IP 每天最多发送 10 次验证码

## 优先级
**P0** - 核心功能，与登录功能配合使用

## 依赖关系
- 依赖 001-user-login 的登录接口
- 复用 001-user-login 的 User 数据模型
